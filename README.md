# Motion Light Detector - Altium PCB Design

## About The Project
This repository contains the hardware design files and manufacturing outputs for a Motion Light Detector. 
The project was completed as the practical assignment for the **"Libraries-2-Output"** module, part of the **Altium Global Scholarship Program**.

My main focus during this project was to master the industry-standard PCB design workflow in Altium Designer, rather than the core circuit architecture.

## Workflow & Skills Applied
* **Component Libraries:** Created custom schematic symbols and footprint models.
* **Schematic Capture:** Wired the circuit and configured project-level Design Rule Checks (DRC).
* **PCB Layout:** Placed components optimizing for signal flow and routed the board successfully.
* **Documentation:** Generated professional assembly drawings using **Altium Draftsman**.
* **Manufacturing Files:** Exported complete Gerber, NC Drill, and BOM files ready for fabrication.
